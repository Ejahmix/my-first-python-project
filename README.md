# First Cloud Project

A beginner Python script that models a cloud engineer's profile
and iterates over AWS services — built while learning Python
fundamentals and Git workflow.

## What it does

Demonstrates core Python concepts — variables, lists, 
dictionaries, loops, and conditionals — using cloud 
engineering as the context.

## Tech stack

- Python 3.12

## Setup

```bash
git clone https://github.com/YOUR-USERNAME/first-cloud-project
cd first-cloud-project
python hello_cloud.py
```

## What I learned

How to use variables, loops, and dictionaries in Python.
How to initialize a Git repo, make commits, and push to GitHub.
How to write a .gitignore and structure a project professionally.
